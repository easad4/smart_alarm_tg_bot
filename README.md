# Интеллектуальный будильник — Telegram-бот

Каждое утро в заданное время присылает пользователю сводку:
- 🌤️ погода в его городе (OpenWeatherMap)
- 💱 курс USD/EUR (ЦБ РФ)
- 📜 исторический факт этого дня (Wikipedia "В этот день")
- 🎉 праздники сегодня (RSS-лента [calend.ru](https://www.calend.ru/holidays/))

## ⚠️ Важно перед запуском

В `history.py` укажите свои контактные данные в `HEADERS["User-Agent"]`.
Wikimedia блокирует запросы с общим/пустым User-Agent (ошибка 403) — там
должно быть название приложения и способ связи (сайт, email, репозиторий):

```python
HEADERS = {
    "User-Agent": "SmartAlarmBot/1.0 (https://ваш-сайт-или-репо; ваш-email@example.com)"
}
```

Подробнее: https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_User-Agent_Policy

## Установка

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и заполните:
   ```bash
   cp .env.example .env
   ```
   - `BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)
   - `OWM_API_KEY` — бесплатный ключ с [openweathermap.org](https://openweathermap.org/api)
   - остальные параметры — значения по умолчанию для новых пользователей

3. Запустите бота:
   ```bash
   python bot.py
   ```

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | подписаться на утреннюю рассылку |
| `/city <город>` | установить город для погоды |
| `/time <ЧЧ:ММ>` | установить время ежедневной рассылки |
| `/now` | прислать сводку сразу, не дожидаясь времени |
| `/stop` | отписаться от рассылки |
| `/help` | показать справку с текущими настройками |

## Как это работает

- Настройки каждого пользователя (город, время, статус подписки) хранятся
  в `users.json` — простое файловое хранилище, ничего дополнительно
  разворачивать не нужно.
- Планировщик (`APScheduler`) каждую минуту проверяет всех подписчиков
  и, если текущее время (в часовом поясе `TIMEZONE`) совпадает с временем
  пользователя, отправляет ему готовую сводку.
- Все внешние запросы (погода, валюта, история, праздники) обёрнуты
  в `try/except` — если один из сервисов недоступен, остальные части
  сообщения всё равно придут.

## Расширение

- Праздники: `holidays.py` разбирает RSS-ленту `today-holidays.rss` с
  calend.ru (она отдаёт праздники "сегодня и завтра"). Если нужно больше
  событий или праздники на другую дату — можно спарсить постраничный
  раздел `https://www.calend.ru/holidays/{год}-{месяц}-{день}/`, но там
  нет официального фида и вёрстка может со временем меняться.
- Часовые пояса на пользователя: сейчас все пользователи используют
  один `TIMEZONE` из `.env`. Чтобы сделать пояс индивидуальным,
  добавьте поле `timezone` в `storage.py` и учитывайте его в
  `check_and_send()` в `bot.py`.
- Для продакшена лучше заменить `users.json` на SQLite/PostgreSQL.
